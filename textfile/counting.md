## 数えられるもの

- 第一種スターリング数
    - [n,k] = [n-1,k-1] + (n-1)[n-1,k] で与えられる
    - n元の順列で，巡回置換分解のサイクル数がちょうどk
    - 入次数と出次数がともに1の有向グラフで，連結成分がk個
    - n人を番号付きのk個の円卓に座らせる方法(k! * [n,k])
    - 左から見た最大値の更新回数がちょうどkの順列
    - ソートに必要な最小swap(任意位置)回数がちょうどmの順列([n,n-m])
    - n頂点の増加根付き森で，連結成分がk個
    - 上昇階乗の係数
    - 固定点がちょうどr個，全サイクル数がk個の順列
        ((n,r)[n-r,k-r]>=2)

- 第二種スターリング数
    - {n,k} = {n-1,k-1} + k{n-1,k} で与えられる
    - n元集合をk個の非空な部分集合に分割する(集合は順序付けない)
    - n元集合からk元集合への全射
    - restricted growth string
        a_1 =1, a_i \leq 1 + max(a_1,...,a_{i-1})
        を満たす数列で，max a_i = kであるものの個数
    - 下降階乗の係数
        D(x,k) = x(x-1)...(x-k+1)としたとき，
        x^n = \sum_{k=0}^n {n,k} D(x,k)
    - {n,k} = (k!)^{-1} \sum_{i=0}^k (-1)^{k-i} (k,i) i^n
        交代和の計算に使える?

## 同値な言い換え

- N要素に対して，「一様ランダムに一要素選び，それに関連する要素を取り除く」を繰り返すときの操作回数の期待値
    <-> (1,...,N)の順列が一様ランダムに与えられ，前の要素から処理を行う．ただし取り除かれた要素は飛ばす
        各要素に対して，その要素で処理が行われる確率を求める
    - 操作回数の期待値 = 各値に対して，その値に対する処理が行われる回数の期待値の総和
    ex) 2024最強コンB
