# Katu2ou C++ Library

競技プログラミング用のライブラリ・テンプレート・学習メモです。

- このリポジトリ: https://github.com/Katu2ou/Katu2ou-Cpro-Library
- ICPC Regional 用ライブラリ: https://github.com/Katu2ou/katu2ou-icpc-regional
- テンプレート: [template/template.cpp](template/template.cpp)、[template/template-fps.cpp](template/template-fps.cpp)

ライブラリは `data-structure/`、`graph/`、`tree/`、`math/`、`string/`、
`convolution/`、`fps-polynomial/` など、分野ごとのディレクトリにあります。

## AtCoderでの参照

提出テンプレートの先頭に、参照先としてリポジトリのトップページURLを記載しています。

```cpp
// Library references:
// https://github.com/Katu2ou/Katu2ou-Cpro-Library
// https://github.com/Katu2ou/katu2ou-icpc-regional
```

[AtCoder生成AI対策ルール](https://info.atcoder.jp/entry/llm-rules-ja)に従い、
事前作成したコードを使用するときは、その使用版をコンテスト開始前にWebで公開し、
コピーして提出するコードに参照URLを残してください。
ローカルで変更しただけのコードは、GitHub上の公開版には反映されません。

各コードに記載された出典・ライセンス表記も確認してください。
